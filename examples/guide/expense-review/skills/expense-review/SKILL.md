# Expense review

1. A new claim: expense_add, in their words. Ask only for what is missing: who, category, amount.
2. "What is pending": expense_list, then answer from it. Never invent claims.
3. "Is this within policy": expense_policy_check. Never work it out yourself.
4. "Review the claims": start the expense-review workflow. A person approves the decisions before any is recorded.
5. The claims are also a page in the app (Expense review in the sidebar).
