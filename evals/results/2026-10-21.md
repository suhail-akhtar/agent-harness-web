17 runs: all six cases on GPT-6 Luna and Claude Haiku 5.5, five on DeepSeek V4.1 Flash
(the long-task `expense-cli` case was not run on DeepSeek this time, to save cost; it
passed there on 2026-10-20 when stopped at 15/18 features).

Harness (a score describes the model and the harness together):

- harness: harness-web 0.1.0, commit 70d03f4 (agents ran on this code; the checks were re-run on b330a13+ checkers)
- settings: maxSteps 150, maxCostUsd 5, compactAt model default, subagentModel session model, gatesOnStop off, subagent depth 1
- plugins: the bundled set
- platform: Windows 11 x64 (native, Git Bash), Node 22.21, Docker Desktop for the sandbox
- judged: hidden checks after each run; then re-judged on the finished workspaces with the
  corrected Windows checkers (no agent re-run): the first pass had three checker bugs of
  its own - a `{{case}}` path that bash on Windows ate the backslashes of, a poppler-only
  deck check, and a URL-shortener check that handed Git Bash's `/tmp` path to Windows
  Python. Each is fixed (Node checkers, quoted forward-slash paths) and covered by a test.
