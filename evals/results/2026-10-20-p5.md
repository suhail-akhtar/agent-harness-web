## Long task (`sdlc/expense-cli`, long-task workflow)

A CLI built feature by feature by fresh agents, judged by a hidden end-to-end test. Stopped early to save budget.

| Model | Features passing | Hidden end-to-end test | Cost / time |
|---|---|---|---|
| GPT-6 Luna | 11/11 (finished) | all pass | $0.15, 43 min |
| DeepSeek Flash | 15/18 (stopped) | all pass on what was built | stopped |
| Claude Haiku 5.5 | 10/26 (stopped) | fails (export not built) | stopped |

- Luna was first scored 2/3: the hidden test compared stderr exactly and this host's Node printed a proxy warning there. The checker now ignores Node's own warnings; re-run on the same workspace, every check passes.
- Haiku's plan put "deleted ids are not reused" (F11) before "delete" (F13). Builders had to take the first unfinished feature and could not reorder the frozen list, so Haiku correctly refused to mark F11 done - for 18 sessions, because the eval approves every "stuck" prompt. Fixed in 001e88b: a builder now builds the feature the next one needs, the planner orders features so each uses only earlier ones, and "stuck" is retried at most three times. **Not yet re-run.**
