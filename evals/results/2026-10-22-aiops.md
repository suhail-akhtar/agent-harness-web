## What the runs found in the harness (all fixed, each with a test that fails without the fix)

- **The machine slept through two runs** (lid closed: 07:22-10:44 and 12:06-12:55). Timers do not count
  suspended time and Docker died under them, so a run looked like a 3.6-hour hang. The runner now sees a
  pause (wall-clock gaps between its 10 s ticks) and leaves such a run unscored (475acb0); both Haiku
  incident runs were caught that way.
- **A model thinking quietly looked like a dead stream.** On the hypothesis step Haiku thought for more than
  180 s with only `ping` events on the wire; the Anthropic SDK drops pings before the harness sees them, so
  the idle timer fired and every retry stalled the same way (the run failed 2/4). Any byte off the wire now
  counts as alive (70186bd).
- **Tool arguments the model broke were fatal.** Sonnet 5.5 fixed the incident correctly after approval,
  then its 6,600-character postmortem call slid into XML parameter tags halfway; the SDK wraps that parse
  error in its own class, which the harness did not treat as retryable (3/4). It is now asked again
  (9dfa6f3); the rerun above passed 4/4 without needing it.
- **A stack test tore down an eval's stack.** Test files and evals share the `hwtest-aiops` compose project;
  test files now take turns through a lock, and evals must not run beside the stack tests.

Haiku is no longer used for live runs (the user's choice, 2026-10-22): Sonnet 5.5 at medium effort
replaces it. Its earlier passes above stay as measured.
